# Guardián de publicación

Franja sobre el chat que avisa cuando algo quedó sin publicar en los repos de la sesión: archivos cambiados que no se han guardado, o cambios guardados que no se han subido a GitHub. La web de El Drim Tim se publica sola en eldrimtim.cr cuando un cambio llega a main, así que lo que no se sube no existe, y se pierde cuando la sesión de la nube se cierra.

La franja se revisa al final de cada respuesta de Claude y desaparece cuando todo está publicado.

## Publicar

- El botón **Publicar** de la franja, o el comando `/publicar`, le pide a Claude que resuma en lenguaje claro qué cambió y qué se va a ver distinto.
- Claude espera el ok antes de guardar y subir.
